# SURFACE-GUIX
Hello! This project is meant to unite users of Microsoft Surface devices with people who run the GNU guix system.


What does this installer have?


The installer is packed with the nonguix firmware additives for support with devices like Microsoft SAM, the marvell wifi chip, and other surface specific quirks.


How do you know this works?


I have personally ran GNU guix system bare metal on my surface laptop 2 with this installer. 


I would like to note that the installer for this system is extremely broken and can take hours to correctly configure I am looking for aid within the community to hopefully fix this installer.
